## 📖 核心功能总览与产品特色

**Fluid Navigation Gestures (流体手势导航)** 是一款专注于带来极致顺滑操作手感的 Android 全面屏手势增强工具。本项目基于经典 FNG 核心底座进行深度重构、代码净化与现代系统规范适配，彻底去除陈旧版本的商业组件与网络依赖，为追求纯净、流畅与高效交互的用户打造：

### 1. 灵动水滴流体物理动效
* **原生 C++ 物理流体引擎**：基于底层 Native 贝塞尔曲线拉伸与真实弹簧阻尼回弹计算，手指划动时水滴如同液体般延展跟随、自然分离，告别传统手势软件生硬僵硬的线性动画。
* **双段式交互设计**：
  * **快速滑动（Quick Swipe）**：轻触边缘向内滑动即可触发主要动作（如返回、主页）；
  * **滑动并按住（Swipe & Hold）**：向内划出更远距离稍作悬停，水滴即刻变色形变，触发次要高级动作（如快速呼出常用应用、分屏、截图）。

### 2. 丰富的高自由度动作映射
* **系统核心动作**：返回、回到桌面、多任务后台（Recents）、**快速切换到上一个应用（规避系统多任务卡死）**、展开通知中心、展开快捷控制开关、单手模式、熄屏锁定、截屏等；
* **应用与快捷方式直达**：支持将任意边缘的长滑/短滑绑定为启动常用 App（如聊天、阅读、记事、工具）或系统快捷方式（Shortcut）。

### 3. 三大边缘触发区任意调校
* **左侧 / 右侧 / 底部独立设置**：支持自由调节各边缘感应区的触发宽度、高度、纵向位置、灵敏度与盲区范围；
* **多键共存与灵活避让**：既可搭配 ADB/Shizuku 彻底隐藏系统导航栏享受全沉浸式屏幕，也能与系统经典三大虚拟按键优雅共存，互不打扰。

### 4. 极致触感与线性马达调校
* 支持系统原生触感反馈与内置多档触觉引擎微调，完美调动现代手机 X 轴线性马达，每一次划出与触发均提供清脆、利落的物理震感确认。

### 5. 绝对安全与物理级 0 联网断网架构
* **物理剥离网络权限**：在 `AndroidManifest.xml` 中连根剔除 `android.permission.INTERNET` 与网络状态权限，系统底层直接封死网络通道，绝无数据泄露或隐私回传的可能；
* **纯净 0 广告 0 追踪**：彻底移除 Google Play Billing、Firebase 统计、广告 SDK 及第三方推广代码；
* **0 待机常驻功耗**：纯事件驱动模式，待机状态不持有任何 WakeLock 唤醒锁，CPU 占用率绝对 0.0%，常驻运行内存仅约 24MB 左右。

### 6. 现代 Android 11 ~ 15 / 纯 64 位架构深度优化
* **Target SDK 29 现代化提升**：消除 Android 14/15 (HyperOS) 上的旧版应用系统拦截警告；
* **存储兼容模式保障**：配置 `requestLegacyExternalStorage`，配置导入导出零权限异常；
* **双架构版本提供**：提供全机型兼容的 Universal ARM 版，以及专为旗舰芯片深度精简的纯 64 位极速版（`FluidNavigationGesture-arm64.apk`）。

## 📱 小米 HyperOS / 主流系统后台防杀保活四部曲

流体手势的核心驱动依靠 Android 系统级的**无障碍服务 (`AccessibilityService`)**。无障碍服务在 Android 进程树中享有极高优先级（`oom_adj <= 2`）。为避免被国内定制系统（如 HyperOS）的极端省电策略误杀，请完成以下 4 步保活设置：

1. **自启动与关联启动**：
   - 进入系统【设置】➔【应用设置】➔【应用管理】➔【流体手势导航】；
   - 开启 **“自启动”** 与 **“允许关联启动”**。
2. **省电策略设为“无限制”**：
   - 在流体手势的应用信息页中，将【省电策略】（电池优化）由默认的“智能推荐”修改为 **“无限制”**。
3. **多任务后台加锁**：
   - 从屏幕底部上滑呼出多任务后台卡片流；
   - 长按“流体手势导航”的预览卡片，点击出现的小锁图标（🔒）进行**锁定**，防止平时点击底部一键清理时被误关。
4. **保持无障碍常驻**：
   - 在【更多设置】➔【无障碍】➔【已下载的应用】中，确保“流体手势导航”始终处于开启状态。

## 🔑 隐藏导航栏（三大金刚键）授权全攻略与实战指南

在开启首页的【隐藏导航栏】胶囊小开关前，需要授予一次系统级权限。以下为详细原理与不同场景下的授权方法：

### 1. 权限本质：为什么软件内不能直接“弹窗允许”？
- **系统安全限制**：隐藏物理/虚拟三大金刚键需要修改 Android 底层全局参数（如 `force_fsg_nav_bar`），该能力受系统最高级开发权限 `android.permission.WRITE_SECURE_SETTINGS` 保护；
- **防流氓机制**：Google 严禁普通应用像索取相机/相册权限那样自行弹出“允许/拒绝”对话框，必须由用户通过 **ADB 调试** 或 **Root** 从系统外部赋予；
- **一次授权，终身有效**：**只需成功授权一次**，日常手机重启、系统更新均不会掉权限，终身永久生效（除非卸载应用）。

---

### 2. 授权方式对比与操作指引

```
┌────────────────────────────────────────────────────────────────────────┐
│  授权途径               设备需求               耗时      是否需要电脑  │
├────────────────────────────────────────────────────────────────────────┤
│  方案 A：手机无线调试    Android 11+ / Wi-Fi    2 分钟    ❌ 纯手机搞定 │
│  方案 B：电脑 USB 调试   数据线 + PC            1 分钟    ✅ 需要电脑   │
│  方案 C：Root / 玩机     已 Root 设备           10 秒     ❌ 纯手机搞定 │
└────────────────────────────────────────────────────────────────────────┘
```

#### 📱 方案 A：免电脑·手机本机无线调试（首选推荐，Android 11+ 通用）
无需数据线，无需电脑，手机连接 Wi-Fi 即可全本地完成：
1. **安装配对工具**：在手机上安装 [Shizuku](https://shizuku.rikka.app/) 或本地终端应用（如 LADB / 搞机工具箱手机版）；
2. **开启无线调试**：进入系统【设置】➔【开发者选项】➔ 开启 **【无线调试】**；
3. **无线配对**：点击【无线调试】➔【使用配对码配对】，利用分屏或下拉通知栏，在 Shizuku 中填入 6 位验证码完成配对并启动；
4. **执行授权**：在配套终端或 Shizuku 授权的终端执行以下命令：
   ```sh
   pm grant com.fb.fluid android.permission.WRITE_SECURE_SETTINGS
   ```
5. 打开流体手势，拨动首页【隐藏导航栏】胶囊小开关，三大键瞬间消失！

---

#### 💻 方案 B：电脑 USB 调试一键授权（经典快捷）
1. **手机开启开发者模式**：
   - 连续点击系统版本号（MIUI/HyperOS 版本号）7 次，激活开发者选项；
   - 进入【更多设置】➔【开发者选项】➔ 开启 **【USB 调试】**；
   - ⚠️ **小米 / HyperOS 关键避坑（必看）**：必须同时开启 **【USB 调试（安全设置）】**（允许通过 USB 模拟点击或修改权限；若未开启，小米系统会强行拦截授权并报错 `SecurityException`）；
2. **连接电脑并运行命令**：
   - 手机用数据线连上电脑，电脑打开终端（PowerShell 或 CMD），输入：
   ```powershell
   adb shell pm grant com.fb.fluid android.permission.WRITE_SECURE_SETTINGS
   ```
   - 终端回车后无任何报错即代表授权成功！
3. 回到流体手势首页，直接拨动【隐藏导航栏】开关即可秒级生效。

---

#### ⚡ 方案 C：已 Root 设备一键极速授权
若设备已获得 Root 权限（Magisk / KernelSU / APatch）：
在手机终端模拟器（Termux）或通过 Root 授权软件直接执行：
```sh

```

  - 最近任务推荐切换为“横向排布”；
  - 关闭 Nova 自身的无障碍，由流体手势独占边缘手势，顺滑如丝。


## 💡 搭配第三方桌面（如 Nova Launcher）的使用技巧与经验

很多极客用户喜欢将 **Nova Launcher + 流体手势** 搭配使用，以下是实战经验总结：

1. **为什么建议保留底部三大虚拟按键作为“双保险”？**
   - 小米系统在检测到第三方桌面时，会限制官方手势并强行回退到三大虚拟按键；
   - 将流体手势配置为主力侧边/底部手势，同时保留底层三大键（或将其设置在最底部），可以在极端游戏全屏或系统偶发死锁时，随时有一条 100% 稳定的物理退路。
2. **如何解决 MIUI/HyperOS 下第三方桌面最近任务“卡住、点不动应用卡片”？**
   - **底层根因（真机抓包定标）**：小米 HyperOS 的多任务后台（`RecentsActivity`）深度缝合在系统桌面（`com.miui.home`）中。当第三方桌面（Nova Launcher）为默认桌面时，动画状态机偶发卡在 `HomeState`。由于没有小米桌面图标（`windowElement=null`），卡片点击事件被系统桌面静默丢弃（Discard），未向系统发出启动指令；
   - **关机重启持久性**：通过 ADB 写入的 `WRITE_SECURE_SETTINGS`、`force_fsg_nav_bar=1` 与系统 AppOps 权限**关机重启绝不丢失**，重启无需再次连电脑。但该点击卡住缺陷属于小米桌面固件本身的兼容性 Bug；
   - **偶发卡住的秒级解药**：点不动卡片时切勿狂点，只需向内划一下侧边手势（返回一次）或点一下底部的“X”（清理任务按钮，触发 `event 9000` 强行重置状态机为 `IdleState`）；
   - **排布方式优化**：进入【设置】➔【桌面】➔【最近任务排列方式】，建议将默认的“纵向排布”切换为 **“横向排布”**（横向单排更契合 AOSP 原生逻辑，能消除大部分私有动画死锁）；
   - **关闭 Nova 自身手势**：在手机无障碍设置中，**关闭 Nova Launcher 自身的无障碍服务**，让流体手势独占手势监听，杜绝双无障碍争抢窗口焦点；
   - **终极配套方案**：在流体手势中将边缘长滑手势绑定为 **“切换到上一个应用”**（或搭配 FV 悬浮球的最近任务切换圆盘），日常来回切换 App 直接侧滑搞定，无需频繁点进系统的多任务卡片流，完美规避系统 bug。
