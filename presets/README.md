# 流体手势推荐手势预设配置 (Recommended Preset)

本目录包含一套经过深度日常使用打磨的优质流体手势配置备份文件 `fng_recommended_preset.zip`。

## 🌟 预设特色
1. **触感反馈**：系统触感级别 3，声音静音，契合当代高规格线性马达的细腻回馈。
2. **触发区黄金比例**：横向宽度 84%，纵向高度 77%，完美兼顾边缘滑动舒适度与日常打字/浏览防误触。
3. **高效手势组合**：
   - 快速短滑：高频返回、回到桌面；
   - 滑动并长按（次要动作）：多任务切换、呼出快捷应用（ChatGPT、微信、飞书、滴答清单语音/快速添加、SearchEVO 浮窗搜索等）。
4. **特定应用防误触**：内置黑名单应用自动暂停手势支持。

## 📥 导入使用方法
1. 在手机上安装并打开最新纯净版 `FluidNavigationGesture.apk`；
2. 授予必要的“无障碍服务”与“显示在其他应用上层”权限；
3. 进入应用主界面，依次点击【高级】➔【备份与恢复】➔【导入设置】；
4. 选择 `fng_recommended_preset.zip` 即可一键恢复全量配置。
